## 🚧 Welcome to the Rat~Lab

This repository is a dedicated graveyard for bad ideas, a laboratory for wild experiments, and a construction site for new skills. It exists for one reason: **to write code, break it completely, and build it back better.**

No best practices. No code reviews. Just trial, error, and learning.

## 🔬 The Loop

1. **Break it:** Push the limits, cause syntax errors, and create infinite loops.
2. **Debug it:** Stare at the stack traces until they make sense.
3. **Build it:** Put the pieces back together into something that actually compiles.
4. **Repeat:** Do it all over again.

## 📂 What's Inside?

- 🌪️ **Chaotic Scripts:** Half-baked ideas and late-night experiments.
- 🐛 **Buggy Prototypes:** Code that is intentionally (or accidentally) flawed.
- 🛠️ **Proof of Concepts:** Small wins and sudden "aha!" moments.

## ⚠️ Disclaimer

**DO NOT USE THIS CODE IN PRODUCTION.**

This is a playground. Code in here is highly volatile, largely undocumented, and liable to spontaneously combust. You have been warned.
